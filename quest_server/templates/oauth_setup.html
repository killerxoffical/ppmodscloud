Google Sign-In চালু করার নিয়ম

সাধারণ ব্যবহারকারীদের জন্য ১-ক্লিক "Sign in with Google" বাটনটি সক্রিয় করতে Render ড্যাশবোর্ডে শুধু গুগলের ফ্রি Client ID যুক্ত করতে হবে (১০০% ফ্রি ও ২ মিনিটের কাজ):

  1. Google Cloud Console-এ যান।
  2. Create Credentials ➔ OAuth client ID সিলেক্ট করুন।
  3. Application type: Web application বেছে নিন।
  4. Authorized redirect URIs বক্সে নিচের লিঙ্কটি কপি করে বসান:
    5. {{ redirect_uri }}
  5. তৈরি শেষে প্রাপ্ত Client ID ও Client Secret কপি করুন।
  6. Render ড্যাশবোর্ডে Environment Variables-এ নিচের ২টি নাম দিয়ে সেভ করুন:
    7. GOOGLE_CLIENT_ID = আপনার_Client_ID
    GOOGLE_CLIENT_SECRET = আপনার_Client_Secret

সেভ করার সাথে সাথে যেকোনো ব্যবহারকারী পাসওয়ার্ড বা টোকেন ছাড়া ১-ক্লিকে সরাসরি গুগল দিয়ে লগইন করতে পারবে!
